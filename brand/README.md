# Intelyx logo

The lettering is converted to vector outlines, so these files look the same everywhere,
with no font installation needed.

| File | Use it for |
|---|---|
| `intelyx-logo.svg` / `.png` | **Primary logo.** White or light backgrounds: website, documents, slides. |
| `intelyx-logo-reversed.svg` / `.png` | Near-black, dark or photo backgrounds. |
| `intelyx-logo-black.svg` | One-colour printing: stamps, invoices, fax, embossing. |
| `intelyx-logo-white.svg` | One colour on dark: merchandise, vehicle and signage cut vinyl. |
| `intelyx-mark.svg`, `intelyx-mark-1024.png` | Icon only: social media profile pictures, app icons, favicons. |
| `intelyx-mark-reversed.svg`, `intelyx-mark-reversed-1024.png` | Icon on dark backgrounds. |

Prefer the **SVG** files (they scale to any size). Use the PNGs (transparent background)
where SVG isn't accepted, e.g. Word, PowerPoint or social media uploads.

## The design

- **Mark:** a rounded near-black tile holding a cream lowercase *i* (dot and stem) and a rising
  terracotta stroke: intelligence moving forward. The dot and the stroke are terracotta.
- **Wordmark:** "Intelyx" in Newsreader Medium, a serif that matches the website's headlines, with
  slightly tightened spacing. The final **x** is terracotta.
- **On dark backgrounds** the tile turns terracotta and the glyphs turn near-black (the
  *reversed* files).

## Clear space and minimum size

- Keep empty space around the logo at least **half the height of the mark** on every side.
- Smallest size: **80px wide** on screen (about 20mm in print) for the full logo, and
  **16px** for the mark on its own.

## Please don't

- Stretch, squash, rotate or add effects (shadows, outlines, gradients) to the logo.
- Change the colours, or put the primary logo on a dark background (use the reversed version).
- Retype the name in another font, or rearrange the mark and wordmark.
- Place it on busy photos without enough contrast.
